Practice calibration

Calibration compares a known flat grid (corners at \((c\,s,\ r\,s,\ 0)\) mm) with where the camera saw those corners. Step one: find the corners in the photo, precisely.

1findChessboardCorners

Local threshold → black quads → glue quads at shared vertices → order row by row. pattern_size counts inner corners; a wrong number gives found = False, never a partial result. Accuracy is about ±1 px.

$$N \times M \text{ squares} \;\Longrightarrow\; \text{pattern\_size} = (N-1,\ M-1), \qquad 6 \times 9 \;\Longrightarrow\; (5,\ 8)$$

found, corners = cv2.findChessboardCorners(gray, (5, 8))

2cornerSubPix

At the true corner \(p\), every pixel \(q\) nearby gives \(\nabla I(q)\cdot(q-p)=0\): on an edge the gradient is perpendicular to the edge through \(p\), in a flat square it is zero. Solve for \(p\) by least squares, move the window, repeat.

$$\Bigl(\sum_{q} \nabla I\,\nabla I^{T}\Bigr)\,p = \sum_{q} \nabla I\,\nabla I^{T}\,q$$ $$\text{stop when } \lVert p_{k+1} - p_k \rVert < 0.001 \text{ px or } k = 30, \qquad \text{winSize} = (11, 11) \Rightarrow 23 \times 23$$
Open this visualization on its own page
criteria = (cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER, 30, 0.001)
corners = cv2.cornerSubPix(gray, corners, (11, 11), (-1, -1), criteria)

3calibrateCamera

Give it the same known 3D grid for every photo and the corners found in each photo. It looks for the camera \(K\), the lens distortion and the pose of the board in each photo that make the projected grid land on the found corners.

Camera model: 3D corner → pixel

$$\mathbf X_c = R_i \mathbf X + \mathbf t_i, \quad x = \frac{X_c}{Z_c},\ y = \frac{Y_c}{Z_c}, \quad r^2 = x^2 + y^2, \quad \begin{aligned} u &= f_x\,x\,(1 + k_1 r^2 + k_2 r^4) + c_x \\ v &= f_y\,y\,(1 + k_1 r^2 + k_2 r^4) + c_y \end{aligned}$$

What it minimises (start: Zhang's closed form without distortion, then Levenberg–Marquardt)

$$\min_{K,\ \text{dist},\ R_i,\ \mathbf t_i} \sum_{i=1}^{\text{photos}} \sum_{k=1}^{40} \bigl\lVert \mathbf u_{ik} - \pi(K, \text{dist}, R_i, \mathbf t_i, \mathbf X_k) \bigr\rVert^2, \qquad \text{rms} = \sqrt{\frac{\text{that sum}}{\#\text{corners}}}$$

SQUARE_MM = 21.5

# 3D corners on the board (plane z = 0), in the same order as in the photo
obj = np.zeros((PATTERN[0] * PATTERN[1], 3), np.float32)
obj[:, :2] = np.mgrid[0:PATTERN[0], 0:PATTERN[1]].T.reshape(-1, 2) * SQUARE_MM
