A toy stereo scene: disparity is computed for every pixel, turned into depth, then each pixel is lifted into a 3D point. The point cloud can be rotated by dragging.

depth map z = b·f / d

near (coral) → far (blue)

each pixel (u, v, d*) →

z = b·f / d*

x = b·(u − oₓ) / d*

y = b·(v − o_y) / d*

point cloud (drag to rotate)
