Pixels to millimetres

Goal: a phone photo that works as a ruler. Put screws on a printed sheet, take a photo, get “3 mm thick, 20 mm long”. Measuring in pixels is easy; the hard part is the number of pixels in one millimetre.

1Obstacle 1 · distance

Raise the phone and the same screw gets smaller on the photo. How many pixels one millimetre is depends on the height \(Z\), which you never know exactly.

$$L_{\text{px}} = \frac{f \cdot L_{\text{mm}}}{Z} \quad\Longrightarrow\quad s = \frac{L_{\text{px}}}{L_{\text{mm}}} = \frac{f}{Z}\ \ \text{px/mm}$$

\(f\) = focal length in pixels (here 3000). Twice as high → half as many pixels per mm.

2Obstacle 2 · tilt

A hand-held phone is always tilted a little. Then the far part of the sheet is deeper than the near part: the rectangle becomes a trapezoid, and the scale is different in every part of the photo.

$$s(u, v) = \frac{f}{Z(u, v)} \qquad Z_{\text{far}} > Z_{\text{near}} \;\Longrightarrow\; s_{\text{far}} < s_{\text{near}}$$

No single “px per mm” is correct for the whole photo.

3Obstacle 3 · lens

The glass bends the picture, most near the edges: straight lines become slight arcs. Phones correct most of it themselves, so what is left is usually small.

$$x_d = x\,(1 + k_1 r^2 + k_2 r^4), \qquad y_d = y\,(1 + k_1 r^2 + k_2 r^4), \qquad r^2 = x^2 + y^2$$

A homography keeps straight lines straight, so it can fix obstacles 1 and 2 but not this one.

4The map: sheet_layout.json

Like four monuments on a city map: we drew the sheet, so we know where every marker is in mm (the json). The detector finds the same corners on the photo in px. Each marker's id says which json row it belongs to.

$$\underbrace{(u_k,\ v_k)}_{\text{photo, px · detector}} \;\longleftrightarrow\; \underbrace{(X_k,\ Y_k)}_{\text{sheet, mm · json}}, \qquad k = 0, 1, 2, 3$$

5From 4 pairs to H

A homography is one 3×3 table that sends any photo pixel to mm on the sheet. It has 8 unknowns; every pair gives 2 equations, so 4 pairs are exactly enough.

The map: multiply, then divide by the third number

$$\begin{bmatrix}x'\\ y'\\ w\end{bmatrix} = \underbrace{\begin{bmatrix}h_{11} & h_{12} & h_{13}\\ h_{21} & h_{22} & h_{23}\\ h_{31} & h_{32} & 1\end{bmatrix}}_{H}\begin{bmatrix}u\\ v\\ 1\end{bmatrix}, \qquad X = \frac{x'}{w}, \quad Y = \frac{y'}{w}$$

The division by \(w\) is what lets far parts of the photo get a different scale than near parts.

One pair → two linear equations (multiply out the fractions)

$$X = \frac{h_{11}u + h_{12}v + h_{13}}{h_{31}u + h_{32}v + 1} \;\Longrightarrow\; h_{11}u + h_{12}v + h_{13} - h_{31}\,uX - h_{32}\,vX = X$$ $$Y = \frac{h_{21}u + h_{22}v + h_{23}}{h_{31}u + h_{32}v + 1} \;\Longrightarrow\; h_{21}u + h_{22}v + h_{23} - h_{31}\,uY - h_{32}\,vY = Y$$

Stack the rows of the 4 pairs: \(A\,\mathbf h = \mathbf b\) with \(A\) of size 8×8. Solve it once per photo.

6Using H on one point

With H known, every pixel of the photo has a place on the sheet. Send both ends of a screw through H, then measure in mm.

$$\text{pixel } (u, v) \xrightarrow{\ \times H\ } (x', y', w) \xrightarrow{\ \div w\ } (X, Y)\ \text{mm}, \qquad L = \sqrt{(X_B - X_A)^2 + (Y_B - Y_A)^2}$$

7Rectify the whole photo

Apply H to the whole photo and you get a view from straight above: the trapezoid is a rectangle again and the scale is the same everywhere. Obstacles 1 and 2 are gone; only the lens is left.

Warping: every pixel of the top view asks where it came from

$$\text{top-view pixel } (i, j) \;\longrightarrow\; (X, Y) = \Bigl(\frac{i}{10},\ \frac{j}{10}\Bigr)\ \text{mm}$$ $$(X, Y) \;\xrightarrow{\ \times H^{-1},\ \div w\ }\; (u, v) \text{ on the photo} \;\longrightarrow\; \text{copy its colour to } (i, j)$$

10 px = 1 mm, so an A4 sheet becomes 2100 × 2970 px.

8In code

The core of rectify.py. Here H maps straight to top-view pixels, so the mm from the json are multiplied by 10.

import json
import cv2
import numpy as np

layout = json.load(open("sheet_layout.json"))        # marker id -> top-left corner in mm
img = cv2.imread("photo.jpg")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# 1. find the markers: 4 corners each (TL, TR, BR, BL) in px, plus their ids
aruco = cv2.aruco
detector = aruco.ArucoDetector(aruco.getPredefinedDictionary(aruco.DICT_4X4_50))  # the dictionary the sheet was made with
corners, ids, _ = detector.detectMarkers(gray)

# 2. pairs: top-left corner on the photo (px)  <->  the same corner on the sheet (mm, from the json)
src = np.array([c[0][0] for c in corners], np.float32)
dst = np.array([layout["markers"][str(i)] for i in ids.flatten()], np.float32)

# 3. homography: photo px -> top-view px (10 px = 1 mm)
H, _ = cv2.findHomography(src, dst * 10)

# 4. warp the whole photo into the top view: 210 x 297 mm = 2100 x 2970 px
top = cv2.warpPerspective(img, H, (2100, 2970))
